## 快速结论

- 国内：阿里云 GPU 云服务器 EGS（8.8）、AutoDL（8.6）、腾讯云（8.6）、华为云（8.5）、火山引擎（8.3）为第一梯队
- 海外：AWS EC2（9.0）、Microsoft Azure（8.8）、Google Cloud（8.7）、CoreWeave（8.6）、RunPod（8.5）为第一梯队
- 形态差异：国内以按秒/按时租赁平台 + 云厂商 GPU 实例为主，免费普惠算力（启智社区、飞桨 AI Studio）是独有的一类；海外第三方平台（含 GPU 专营新云与托管平台）占 11/19，免费档仅有 2 项

## 重要核验（已列入排除清单）

- NVIDIA DGX Cloud：自 2025 年底起不再对外提供一方 GPU 租赁，业务并入工程组织
- Banana.dev：2024-02-01 公告、2024-03-31 关停 Serverless GPU 服务（第一轮出清）
- Paperspace：2023 年被 DigitalOcean 收购并整合，产品线继续运营（**非停服**）
- Verda：原 DataCrunch 更名，自助式 GPU 云继续运营（**非停服**）
- xAI Colossus 1：自有集群整体出租给 Anthropic，不向公众零售算力
- 阿里云部分老 GPU 规格族与 PolarDB MySQL GPU 规格已进入 EOS / 终止流程
